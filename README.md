# Beyond Code - Hybrid Blog Project

## 📌 Project Overview

Beyond Code is a **hybrid blog project** designed to showcase insights on **Tech & Coding, Blockchain/Web3, and Productivity & Mindset**. This project features a **modern single-page layout** with dynamic blog content, an interactive sidebar, and a **dark/light mode toggle** for an improved reading experience.

## 🚀 Features

- **Dark/Light Mode Toggle** 🌗
- **Dynamic Blog Post Loading** (from `posts.json`)
- **Interactive Sidebar** with Categories, Recent Posts & Quote of the Day
- **Smooth Scrolling Navigation**
- **Modals for Full Blog Post View**

## 🛠 Tech Stack

- **Frontend:** HTML, CSS, JavaScript
- **Styling:** Vanilla CSS, Custom Fonts
- **Functionality:** JavaScript for dynamic content & UI interactions
- **Version Control:** Git & GitHub

## 📌 How to Run the Project

1. Clone the repository:
   ```bash
   git clone https://github.com/Eagle-lucid/beyond-code.git
   ```
2. Open `index.html` in your browser.
3. Start coding and customize the blog as needed!
